LangBang

Polish practice for Android tablets — neural TTS, generated example sentences, phoneme-level pronunciation scoring.

What it is

LangBang is a personal-use Android tablet app for learning Polish. It runs natively on Samsung Galaxy Tab and similar hardware — landscape-first, tap-to-hear, no ads, no account required.

Lessons cover Polish phonemes, the most common verbs (with full present-tense paradigms), and the most common adjectives (with all nominative and accusative forms). Gemini generates short example sentences on demand; Azure neural TTS pronounces them; Azure Pronunciation Assessment scores how close your attempt was.

Builds

APKs are published to the alpacapps R2 bucket. Easiest install: scan the QR on the tablet and tap through (Settings will prompt to allow install from unknown sources). No cable, no adb.

Scan to install

Point the tablet camera at the code — it opens langbang-latest.apk straight from R2. Tap the download, then tap the file to install.

Audio downloads itself on first launch (wifi) — no extra step.

Features

  • Lesson 1 — Pronunciation. 19 Polish phonemes (ą ę ó y ł w c ch r ć ś ń ż rz ź sz cz dz dź dż) with IPA, English approximations, and 10 example words each. Flashcard quiz mode.
  • Lesson 2 — Core verbs. 22 most common verbs with full 6-row present-tense paradigms, grouped by conjugation class. By-pronoun mode + add-your-own via Gemini translation. Generated example sentences with EN→PL→EN→PL playback.
  • Lesson 3 — Core adjectives. 40 most common adjectives with nominative and accusative paradigms across all five gender/number forms. Same sentence-generation flow as verbs.
  • Lesson 4 — Common adverbs. Uninflected high-frequency adverbs (razem, dzisiaj, jutro, teraz, chętnie) — one form covers every gender, number, and case. Same TTS + Gemini sentence-generation + pronunciation-scoring loop as the other lessons. Add-your-own supported.
  • Pronunciation scoring. Tap the mic on any word — Azure Pronunciation Assessment returns a 0–100 accuracy score with color-coded inline feedback.
  • Offline-friendly. Every Polish utterance and English gloss is pre-synthesized to cached mp3 at first launch, so practice continues without network.
  • SFTP backup. One-tap backup of cached audio + user data to ALPUCA over Tailscale.
  • Spend tracking. Live estimate of Azure TTS + Pronunciation + Gemini token costs in Settings.

Backend

LangBang shares the alpacapps Supabase project — same instance, dedicated langbang schema for isolation. The Android client uses the supabase-kt SDK configured with defaultSchema = "langbang", so requests land in the right namespace without colliding with the alpacapps public schema.

Schema-creation migration lives in the alpacapps repo at supabase/migrations/20260520_langbang_schema.sql. To expose it via PostgREST, the langbang schema must be added to Project Settings → API → Exposed schemas in Supabase Studio.
