Custom Booking System

Purpose-built appointment scheduling to replace WooCommerce — designed specifically for healthcare/wellness services.

Why custom instead of Calendly? Full control over the booking flow, tighter integration with the site's design, Stripe deposit collection, and no per-seat SaaS fees. The system is built once and runs at zero marginal cost.

4. Enter InfoName, email, phone. Intake form acknowledgment checkbox.
5. Pay DepositStripe-powered payment for deposit. Supports bank transfer (ACH) and card payments.

Data Migration Process

Four-step process to move everything from WordPress to the new stack.

  1. Export from WordPress
    Extract all content via WordPress REST API — pages, blog posts, media library, WooCommerce products. Download all images and documents. Export form submission history as CSV for reference.
  2. Transform Content
    Strip WordPress shortcodes and page builder markup. Rebuild each page as clean HTML + Tailwind. Convert blog posts to markdown and insert into the posts table. Re-upload media to Supabase Storage / Cloudflare R2 and update all image URLs.
  3. Configure Services
    Set up Supabase database tables. Configure Stripe for payments. Set up Resend for email. Wire third-party scripts (GTM, Pixel, LiveChat). Populate booking services and provider availability.
  4. DNS Cutover
    Run both sites in parallel for 1-2 weeks. Point within.center DNS to GitHub Pages. GitHub auto-provisions HTTPS. Verify all pages, forms, and analytics work. Decommission WordPress hosting.

URL preservation: All WordPress URL slugs are matched exactly so existing Google rankings and backlinks don't break. Updated sitemap submitted to Google Search Console.
