New Machine Setup

Port Your Project to a New Laptop

Everything you need to get your AlpacApps project running on a fresh machine. About 15 minutes.

You already have these (nothing to create)

  • GitHub account & repo
  • Supabase project
  • Claude Code account
  • Your app is live on GitHub Pages
1

Install Prerequisites

Open Terminal (search for it in Spotlight or find it in Applications → Utilities) and run these one at a time:

# Install Homebrew (Mac package manager)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install Git
brew install git

# Install Node.js (needed for CSS builds)
brew install node

# Verify everything installed
git --version    # should print git version 2.x
node --version   # should print v18+ or v20+
npm --version    # should print 9+ or 10+
Already have Homebrew? Skip the first command. If git --version already works, skip that too. You just need Git and Node.js.
2

Set Up GitHub SSH

SSH keys let your laptop push code to GitHub without typing your password every time.

# Generate a new SSH key (press Enter for all prompts)
ssh-keygen -t ed25519 -C "your-email@example.com"

# Start the SSH agent
eval "$(ssh-agent -s)"

# Add your key to the agent
ssh-add ~/.ssh/id_ed25519

# Copy your public key to clipboard
pbcopy < ~/.ssh/id_ed25519.pub

Now add the key to GitHub:

  1. Go to github.com/settings/ssh/new
  2. Give it a title like "New Laptop"
  3. Paste the key (it's already on your clipboard from pbcopy)
  4. Click Add SSH key
# Test the connection
ssh -T git@github.com
# Should say: "Hi callisummer! You've successfully authenticated..."
3

Clone Your Repo

Pull down your project and install dependencies:

# Go to your home folder (or wherever you keep projects)
cd ~/Documents

# Clone your repo
git clone git@github.com:callisummer/CalliApp.git

# Move into the project
cd CalliApp

# Install npm dependencies (Tailwind CSS, etc.)
npm install
Different repo name? Replace callisummer/CalliApp with your actual GitHub username and repo name. You can find it at the top of your repo page on GitHub.
4

Install Claude Code

Claude Code is your AI developer. It lives in the terminal and builds your app with you.

# Install Claude Code
npm install -g @anthropic-ai/claude-code

# Open your project in Claude Code
cd ~/Documents/CalliApp
claude

The first time you run claude, it will open your browser to log in with your Anthropic account. Once logged in, you're connected.

One-time setup: Inside Claude Code, type this command to enable code intelligence:
/plugin install typescript-lsp@claude-plugins-official
5

Restore Your Credentials

Your API keys and settings are not stored in GitHub (for security). You need three things from Supabase, then Claude Code handles the rest.

5a. Generate a Supabase Management API token

This token lets Claude Code manage your project automatically (fetch keys, run migrations, etc.). You only need to do this once.

  1. Go to supabase.com/dashboard/account/tokens
  2. Click Generate new token
  3. Name it anything (e.g. "Claude Code")
  4. Set expiration to Never
  5. Copy the token (starts with sbp_) — you won't see it again
Where's my project ref? On your Supabase dashboard, click your project. The ref is in the URL: supabase.com/dashboard/project/abcdefghijk. Your database password is what you set when you created the project.

6

Run the Setup Wizard

This is the step where Claude Code configures your project for what you're building. It will ask you one question:

What are you building?

Based on your answer, Claude Code will set up your project as one of two profiles:

Property Management

Renters, bookings, events, smart home devices, resident portal, Airbnb sync — everything for managing physical spaces.

Personal / Business

SaaS apps, portfolios, CRMs, booking systems, personal tools — clean framework without property modules.

In Claude Code, type:

set up my project infrastructure

Claude Code will:

  1. Ask what you're building and which optional services you need (email, SMS, payments, e-signatures, AI, etc.)
  2. Choose the right profile and prune modules you don't need so your codebase stays clean
  3. Configure .claudeignore, create your database tables, set up auth, and push everything
Don't skip this step. If you don't run the setup wizard, your project will have all the property management modules cluttering your codebase even if you don't need them.
7

Verify Everything Works

Run through this checklist to make sure your new machine is fully set up:

  • Git push works — git status shows your repo, git push succeeds
  • CSS build works — npm run css:build runs without errors
  • Claude Code opens — claude starts and you see the prompt
  • Supabase linked — supabase status shows your project ref
  • Credentials exist — CLAUDE.local.md and docs/CREDENTIALS.md are present
  • Site is live — push a small change and see it deploy to your GitHub Pages URL

You're all set!

Your new machine is ready. Push to main and your site auto-deploys to GitHub Pages. Claude Code handles everything else.
