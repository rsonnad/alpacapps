Core system requirements. macOS (desktop app): macOS 11 Big Sur or higher per official docs; some users report the latest builds need macOS 12+, so Monterey or newer is safest. Windows (desktop app): Windows 10 or higher. General hardware & network (practical): modern multi‑core CPU, at least 8–16 GB RAM, SSD recommended.
