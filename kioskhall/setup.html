Tablet Setup Instructions

Follow these steps after an OS update or when Tailscale / ADB stops working.

🔗 Fix Tailscale Auto-Start

  1. Open Settings → Apps → Tailscale
  2. Tap Battery → set to Unrestricted
  3. Go back, tap Permissions → grant all
  4. Open the Tailscale app → make sure VPN toggle is ON
  5. Tailscale should now auto-reconnect after reboots
After OS updates: Samsung resets battery optimization to defaults. You may need to repeat steps 1-2.

💻 ADB Commands (from a computer)

If you have ADB connected, run these to persist settings across updates:

  1. Whitelist Tailscale from battery optimization:
    adb shell dumpsys deviceidle whitelist +com.tailscale.ipn
  2. Allow background running:
    adb shell cmd appops set com.tailscale.ipn RUN_IN_BACKGROUND allow
  3. Disable OS auto-updates:
    adb shell settings put global auto_update 0
  4. Disable Samsung OTA agent:
    adb shell pm disable-user --user 0 com.sec.android.soagent
  5. Disable Galaxy Store auto-updates:
    adb shell pm disable-user --user 0 com.sec.android.app.samsungapps

📡 Re-enable Wireless Debugging

  1. Exit kiosk: triple-tap bottom-right corner (password: 1234)
  2. Open Settings → Developer Options
  3. Toggle Wireless Debugging → ON
  4. Note the IP and port shown
  5. From a computer:
    adb pair <ip>:<pair-port>
    Enter the pairing code
  6. Then connect:
    adb connect <ip>:<connect-port>

🚫 Disable Auto-Updates (Manual)

  1. Open Settings → Software Update
  2. Turn OFF Auto download over Wi-Fi
  3. Turn OFF Auto install (if shown)
  4. Open Galaxy Store → Settings
  5. Turn OFF Auto update apps
Why disable updates? OS updates reset developer options, Tailscale settings, and can change the tablet's IP — causing it to go offline.
