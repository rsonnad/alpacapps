What this tracks. Each night a job on the always-on Oracle Phoenix server SSHes into Alpuca over Tailscale and records: memory pressure (swap, compressor, free), the moondream-indexer runaway-process hazard, any oversized Python process, boot & external-volume usage (PortoSams2T, rvault20), the gme-sniffer + memory-pressure-guard watchdogs, recent guard kills, the Ollama model server, and the Home Assistant VM. A daily summary is also emailed.
